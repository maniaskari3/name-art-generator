# Name Art Generator



A simple command-line Python program that converts a user's name into text-based art using custom character patterns.



### Features



* Converts lowercase letters to uppercase.
* Supports all English letters (A–Z).
* Supports spaces between words.
* Supports periods.
* Displays each character using a custom ASCII-style pattern.
* Handles unsupported characters.



### Example



Enter your name:



Mani



The program displays each letter using a custom character pattern.
